## Before Session 1

Install these three tools:

1. **VS Code** — [code.visualstudio.com](https://code.visualstudio.com)
2. **GitHub Desktop** — [desktop.github.com](https://desktop.github.com)
3. **GitHub account** — [github.com](https://github.com)

## How to use this repo

Each session lives in `sessions/`. Inside each:

- `plan.md` — session flow and demo script (facilitator use)
- `cheat-sheet.md` — your reference during and after the session
- `demo/` — files used in the live demo (open `index.html` in browser)

## Quick start — Session 1 activity

1. Open GitHub Desktop
2. File → Clone Repository → paste this repo URL
3. Open the folder in VS Code
4. Open `sessions/session-01/demo/index.html` in your browser

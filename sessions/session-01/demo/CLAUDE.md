# AI Workshop — Demo Project

## What this is

Demo project for GotPhoto's AI Workshop Series — Session 1: Intro.

## Stack

- HTML + Tailwind CSS via CDN
- No build step — open `index.html` directly in browser
- No dependencies to install

## Purpose

This folder demonstrates:
- What a project folder looks like
- How `CLAUDE.md` gives AI context on every session start
- How `context.md` stores human-readable notes alongside AI context
- What a Tailwind-powered HTML page looks like without any build tooling

## For participants

Open `index.html` in your browser. This is your Session 1 reference guide.

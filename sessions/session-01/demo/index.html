Topics

10 concepts

Dev Tools

IDE & Markdown

Your coding home base. VS Code shows your files, runs code, and integrates AI assistants. Markdown (.md) is plain text with light formatting — the language AI reads natively.

Dev Tools

The Terminal (CLI)

Text interface to your computer. Faster than clicking. cd navigates, ls lists files, mkdir creates folders.

Web Dev

React / Next.js / TS

React builds UIs from reusable components — like Figma components but in code. Next.js adds routing and server features. TypeScript adds type safety so AI makes fewer mistakes.

React docs ↗ TypeScript basics ↗ Next.js intro ↗

UI / UX

Tailwind CSS

Design via utility classes in HTML. p-4 text-white rounded-lg — like Figma's Auto Layout constraints written directly in markup.

Dev Tools

Local Environment

Run your app on your own machine before publishing. localhost:3000 is your private preview — only you can see it until you deploy.

Version Control

Versioning

Every saved state of your project lives in history. Nothing is truly deleted. Branches let you experiment without touching the main working version.

Version Control

Git Basics

The version control engine. Commit = save a snapshot. Branch = parallel version. Merge = combine work. Push = upload to GitHub.

Version Control

GitHub Desktop

Git with a visual interface. See your changes, write commit messages, push to GitHub — no terminal required. Best starting point for non-engineers.

Web Dev

APIs & REST

How apps exchange data. GET fetches. POST creates. Like a waiter — you send a request, the server sends back a JSON response. Claude itself is accessed via API.

AI

MCP Protocol

Claude's plugin system. Connects AI to local files, Figma, Slack, or databases. Write it once and Claude reads your design files directly — no copy-pasting.

Quick Commands

Terminal reference

Navigation

  • cd folder Enter a folder
  • cd .. Go up one level
  • ls List files in folder
  • pwd Show current path
  • mkdir name Create new folder

Git

  • git status What changed?
  • git add . Stage all changes
  • git commit -m Save a snapshot
  • git push Upload to GitHub
  • git clone URL Download a repo

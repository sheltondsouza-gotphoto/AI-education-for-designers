Package Managers

Host runs Claude (Claude Desktop / Claude Code). Client lives inside the host and speaks the MCP protocol. Server exposes tools — Figma, Slack, your filesystem.

Quick Commands

Terminal reference

npm

  • npm install Install dependencies
  • npm run dev Start dev server
  • npm run build Compile for production
  • npm install pkg Add a package
  • npm run … Run any script

Git

  • git status What changed?
  • git pull Download latest
  • git branch name Create a branch
  • git checkout name Switch branch
  • git log --oneline Compact history

GitHub CLI (gh)

  • gh auth login Authenticate
  • gh repo view --web Open repo in browser
  • gh pr list Show open PRs
  • gh pr create Open a pull request
  • gh repo clone … Clone a repo

package.json — what npm run dev actually does 

{
  "scripts": {
    "dev":     "vite",          ← npm run dev runs this
    "build":   "vite build",    ← compiles for production
    "preview": "vite preview"      ← serves the built output
  },
  "dependencies": {
    "react": "^18.2.0"          ← shipped to users
  },
  "devDependencies": {
    "vite": "^4.4.5"           ← build tools only, never shipped
  }
}

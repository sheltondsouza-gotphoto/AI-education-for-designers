# Session Structure Decisions — 2026-04-14

## What was decided

- **45 min per session** — short format to keep attendance high.
- **Try all 10 topics in Session 1** — breadth-first. Split into two sessions if too dense on the day.
- **Hybrid format** — in-person + remote. Demos must be smooth; avoid live setup that can break.
- **1 cheat sheet per session** — all topics in one file, lives in the session folder.
- **Clone activity is the only live hands-on in Session 1** — Activities 1 & 2 (GitHub Page, folder structure) moved to async homework. Too slow for hybrid beginners in 45 min.
- **Pre-session prereqs** — participants install VS Code, GitHub Desktop, create GitHub account before Friday.
- **Repo structure** — minimal folders (`sessions/`, `decisions/`) per CLAUDE.md guidelines. Expand as output grows.

## What was rejected

- Splitting Session 1 into two sessions upfront — try all topics first, split on the day if needed.
- One cheat sheet per topic — too granular.
- Deep-dive format per topic — not enough time at 45 min/session.

## Audience

- 5 people, mixed skill, assume beginner
- Weekly cadence
